Installation

Installer votre abonnement IPTV Suisse

La configuration se fait en quelques minutes, quel que soit votre appareil. Voici la marche à suivre.

1. Choisissez et confirmez votre formule

Contactez-nous sur WhatsApp pour choisir votre durée et votre nombre de connexions simultanées (1, 2 ou 3 appareils). Le détail des tarifs est disponible en ligne.

2. Recevez vos identifiants

Après confirmation, vos identifiants de connexion vous sont transmis directement sur WhatsApp, accompagnés des instructions adaptées à votre appareil.

3. Installez une application compatible

Selon votre appareil :

  • Smart TV (Samsung, LG, Android TV) — application disponible via le magasin d'applications de votre téléviseur.
  • Box Android / Fire TV — installation via le Play Store ou l'Amazon App Store.
  • iOS / tvOS — application disponible sur l'App Store.
  • Windows — application de bureau ou lecteur compatible.
  • Boîtier IPTV — configuration selon le modèle, nous vous guidons si besoin.

4. Connectez-vous et profitez du service

Renseignez vos identifiants dans l'application, puis lancez une chaîne en direct pour confirmer que tout fonctionne correctement.

Besoin d'aide ? Notre support est disponible sur WhatsApp pour vous accompagner dans l'installation, quel que soit votre appareil. Pour plusieurs écrans à la maison, voir aussi nos forfaits multi-écrans.

D'autres questions sur le fonctionnement du service ? Consultez notre FAQ complète.

Une difficulté à l'installation ?

Écrivez-nous sur WhatsApp, nous vous guidons étape par étape.
